# JR Systems - Gerador de Assinaturas Corporativas

Sistema profissional para criação de assinaturas corporativas de e-mail desenvolvido pela JR Systems.

---

# ✨ Recursos

* Interface moderna e responsiva
* Tema Light/Dark
* Pré-visualização em tempo real
* Exportação PNG
* Exportação HTML
* Copiar assinatura para área de transferência
* Sistema de modelos salvos
* Geração em massa via Excel
* Multi-layout corporativo
* Sistema de licenciamento
* Atualização automática via GitHub
* Instalador profissional

---

# 🖼️ Modelos Disponíveis

* PneusVisa Classic
* DNA Pneus Modern

---

# 📦 Instalação

1. Baixe a versão mais recente na aba Releases
2. Execute o instalador
3. Conclua a instalação normalmente
4. Abra o sistema
